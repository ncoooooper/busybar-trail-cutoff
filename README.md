# Trail Cutoff

Check race cutoff times, mark crossings and calculate the pace needed to make the next trail checkpoint.

Set increasingly distant checkpoints as cumulative km|minutes from the race start, separated by commas. Press Start at the start line. Click when you reach the next checkpoint. Wheel previews checkpoint budgets assuming your most recently recorded distance. Hold the wheel undoes the last mark. Hold Start then click confirms a race reset.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
